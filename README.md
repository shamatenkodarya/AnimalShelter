# Добрый друг

Веб-приложение приюта для животных. Новая версия работает на Java 17+ и использует HTML, CSS и JavaScript без внешних библиотек. Старые каталоги `BLL`, `DAL` и `WEB` содержат исходную версию на ASP.NET и оставлены для сравнения; рабочая версия находится в `java/`.

## Запуск

В PowerShell из корня проекта:

```powershell
./run.ps1
```

Откройте <http://127.0.0.1:8080>. При первом запуске приложение создаст администратора `admin@animalshelter.local`. Задайте пароль заранее через переменную окружения `SHELTER_ADMIN_PASSWORD` (минимум 12 символов) или возьмите автоматически созданный пароль из консоли первого запуска. Данные сохраняются в `data/shelter.bin` между запусками.

При первом запуске в пустое хранилище добавляются демонстрационные карточки животных, заявки и отзывы. Они помечены как примеры и не являются реальными данными приюта; изображения животных также созданы для демонстрации. Заполнение выполняется один раз; ваши последующие изменения не сбрасываются. Для заполнения уже созданного пустого хранилища можно выполнить `javac -encoding UTF-8 -d java/out java/src/ru/dobrydrug/Main.java java/src/ru/dobrydrug/SeedData.java`, затем `java -cp java/out ru.dobrydrug.SeedData` и перезапустить приложение.

Необязательные переменные окружения: `PORT` для порта (по умолчанию 8080) и `SHELTER_DATA` для пути к файлу данных.

## Возможности и роли

| Роль | Доступ |
| --- | --- |
| Посетитель | Каталог, фильтры, заявки на адопцию, свои заявки, отзывы |
| Консультант | Обработка заявок и регистрация передачи животного |
| Менеджер | Карточки животных, прививки, просмотр заявок и отчетов |
| Контролер | Отчеты за выбранный период |
| Администратор | Все рабочие функции, учетные записи, роли и модерация отзывов |

При завершении одобренной заявки питомец автоматически помечается пристроенным и исключается из каталога доступных. История смены статусов сохраняется. Отчеты содержат поступления, пристройства, состав по видам, полу и возрасту и месячную динамику адопций.

Данные старой базы SQL Server автоматически не переносятся: в репозитории нет самой базы или выгрузки. Для переноса существующих записей потребуется отдельный экспорт.

## Проверка

```powershell
$env:SHELTER_DATA = 'java/test-data/smoke.bin'
javac -encoding UTF-8 -d java/out java/src/ru/dobrydrug/Main.java java/src/ru/dobrydrug/SeedData.java java/src/ru/dobrydrug/SmokeTest.java
java -ea -cp java/out ru.dobrydrug.SmokeTest
```

Проверка охватывает карточки, вакцинации, заявки, смену статусов, права доступа и отчеты без открытия сетевого порта. Для проверки синтаксиса интерфейса можно запустить `node --check java/web/app.js`.
